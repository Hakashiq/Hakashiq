### 🎯 [InterviewIQ — AI-Assisted Mock Interview Platform](https://github.com/Hakashiq/Interview-IQ)

A full-stack platform for resume analysis, skill assessment, AI-assisted mock interviews, and personalized learning recommendations.

**Tech Stack:** Java, Spring Boot, React, MySQL, Redis, FastAPI, LLM APIs

- Designed REST APIs using a layered Spring Boot architecture.
- Integrated AI services for resume analysis and interview evaluation.
- Used Redis caching to reduce repeated data retrieval.

[🌐 Live Demo](https://interviewiq-frontend-inwa.onrender.com) · [📂 Repository](https://github.com/Hakashiq/Interview-IQ)

### 🛍️ [RentTech — Equipment Rental Marketplace](https://github.com/Hakashiq/RentTech-Rental-Marketplace)

A peer-to-peer equipment rental marketplace with booking, availability, and conflict-detection workflows.

**Tech Stack:** Java, Spring Boot, Spring Security, React, MySQL, Spring Data JPA, JWT

- Implemented booking validation and overlapping-booking checks.
- Developed REST APIs and integrated the React frontend.
- Used database indexing to support equipment search and filtering.

[🌐 Live Demo](https://rent-tech-rental-marketplace.vercel.app) · [📂 Repository](https://github.com/Hakashiq/RentTech-Rental-Marketplace)

### ⚖️ [Bidding Service — Auction Backend](https://github.com/Hakashiq/Bidding-Service-Backend-Application)

A Java backend application supporting open auctions and sealed tenders through RESTful APIs.

**Tech Stack:** Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Maven, JUnit, Mockito

- Implemented event creation, bid submission, and closing-time validation.
- Supported separate bid records for open auctions and revision history for sealed tenders.
- Implemented bid visibility rules and winner-selection logic.
- Wrote automated tests for bidding rules, deadline boundaries, and sealed-tender privacy.

[📂 Repository](https://github.com/Hakashiq/Bidding-Service-Backend-Application)
